# Meu Portfólio

Site de portfólio pessoal com layout responsivo, seções de apresentação, habilidades, qualificações, serviços, projetos e contato.

## Visão Geral
- Página única (SPA) em HTML/CSS/JS
- Layout responsivo com mobile-first
- Tema claro/escuro
- Conteúdo com foco em Python, backend, automação e diagnóstico de falhas
- Habilidades descritas por aplicações concretas
- Quatro projetos autorais com links para os repositórios
- Métricas de atendimentos com período e definição explícitos
- Seções com conteúdo organizado e foco em usabilidade

## Tecnologias
- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (vanilla)
- Unicons

- Seção de serviços com expansão suave ao passar o mouse

## Métricas

O recorte de 04/07/2024 a 08/10/2026 registra 150 atendimentos concluídos com atividade documentada, incluindo 44 de alta prioridade e 30 categorias distintas. Os números se referem ao recorte auditado, não ao total histórico de incidentes ou a uma taxa de redução de falhas. Nenhum registro individual de atendimento é publicado no site.
